Build log format

The server plugin writes one event per build action. Positions are in metres, rotation is yaw in degrees. Terrain and rock formations are optional.

{
  "name": "My Bunker Base",
  "setting": "rock",            // open | rock | cave | cliff
  "source": "recorded",         // recorded | copypaste
  "terrain": { "size": 72, "res": 49, "heights": [ ... ] },
  "features": [ { "type": "rock.anvil", "pos": [0, 0, 0], "rot": 0 } ],
  "events": [
    { "t": 4.2, "op": "place", "id": 1, "prefab": "foundation",
      "grade": "twigs", "pos": [0, 0, 0], "rot": 0 },
    { "t": 61.0, "op": "upgrade", "id": 1, "grade": "stone" },
    { "t": 64.3, "op": "rotate", "id": 1, "rot": 90 },
    { "t": 75.5, "op": "remove", "id": 1 }
  ]
}

Grades: twigs, wood, stone, metal, toptier. Prefabs: foundation, wall, wall.doorway, wall.window, wall.half, wall.low, wall.frame, floor, floor.frame, block.stair.ushape, door.hinged.metal, cupboard.tool.deployed, box.wooden.large, furnace, sleepingbag_leather_deployed. Formations: rock.anvil, rock.cliff, cave.small. Unknown prefabs show as grey blocks.
